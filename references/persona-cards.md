# 作者人设卡（Per-作品风格身份证）

> 为什么需要：一个组合里多份作品如果拟人化方式一样，
> 等于把"AI 的均匀"换成了"同一支笔的均匀"——互相还是像。
> 每份作品开工前（或改写前）先填一张卡，写进该项目的
> `DECISIONS.md`，改写全程按卡执行。
> 相邻两份至少在"拼写习惯"和"注释主风格"上错开。

## 卡片模板（复制即用）

```markdown
## 人设卡：<作品名 / slug>
- 拼写习惯：全拼 / 缩写 / 混合（写明比例倾向）
- 高频词表（15-25 个）：
- 注释主风格（从五种里选 2-3）：自言自语 / 踩坑记录 / 讲为什么 / TODO / 口径对齐
- 注释密度：整体 __%，重点文件 __%
- 格式化偏好：f-string : % : format = __ : __ : __；os.path / pathlib
- 命名前后缀惯用：
- TODO 残留（2-5 处，写明主题）：
- 本份禁止项（防撞邻份）：
- 函数长度气质：多数 <20 行 / 允许 2-4 个 40-60 行大函数
```

## 示例卡 A：稳重型全拼（适合第一份）

```markdown
## 人设卡：家庭水族箱养护管理系统
- 拼写习惯：全拼为主（局部变量 80% 全拼、20% 英文）
- 高频词表：yanggang, huan_shui, wei_shi, shui_zhi, jilu, tianjia,
  shanchu, chaxun, beizhu, riqi, shuliang, tishi, baocun, fanye, tongji
- 注释主风格：讲为什么 + 口径对齐
- 注释密度：整体 25%，models.py / 前 30 页文件 32%
- 格式化偏好：f-string : % = 6 : 4；os.path
- 命名前后缀：`_ls`、`_cnt`、`my_`
- TODO 残留：3 处（导出 Excel、水质预警推送、批量喂食）
- 本份禁止项：不用缩写拼法；不用 .format()
- 函数长度气质：多数 <20 行，2 个大函数（种子数据、月度统计）
```

## 示例卡 B：缩写+%格式化（和 A 错开）

```markdown
## 人设卡：婴幼儿育儿记录与成长管理系统
- 拼写习惯：缩写为主（jl=记录 yh=用户 tj=添加 sc=删除…，缩写表见 DECISIONS）
- 高频词表：jl, yh, tj, sc, xg, bd, rq, sj_time, nl(月龄), wyl(喂养量)
- 注释主风格：踩坑记录 + 自言自语
- 注释密度：整体 30%，routes 头部文件 35%
- 格式化偏好：% 为主（f-string 仅模板里）；os.path
- 命名前后缀：`_txt`、`_map`、`cur_`
- TODO 残留：4 处（生长曲线对比、疫苗提醒、多宝档案、打印周报）
- 本份禁止项：不用全拼长词（如 shanchu 出现即返工）；不用 f-string 于 py
- 函数长度气质：多数 <15 行，1 个 60 行大函数（喂养统计）
```

## 示例卡 C：混合口语型（再错开）

```markdown
## 人设卡：个人求职应聘与面试管理系统
- 拼写习惯：混合（公司/职位类名词用英文 company/job，动作词用拼音）
- 高频词表：toudi(投递), mianshi, fankui, yaoqing, offer_ls, gongsi,
  gangwei, jindu(进度), beiwang, rili(日历)
- 注释主风格：自言自语 + TODO
- 注释密度：整体 22%，app.py 与首个蓝图 30%
- 格式化偏好：f-string : format = 5 : 5；os.path 为主、utils 里用一次 pathlib
- 命名前后缀：`_cnt`、`old_/new_`
- TODO 残留：2 处（邮件提醒、面试题库导入）
- 本份禁止项：不用踩坑记录式注释（和 B 撞）；不用 `_ls` 后缀（A 在用）
- 函数长度气质：多数 <25 行，3 个 40 行档
```

## 组合级检查（每新增一份跑一次）

1. 新卡与**相邻两份**的卡在拼写习惯、注释主风格、前后缀上至少各差一项；
2. 高频词表与邻份重叠 ≤3 个词；
3. 全组合跑 `similarity_check`：新份对所有既有作品 ≤35%，
   且拼音化后热点应**下降**（下降 = 拟人化起了去同源作用）。
